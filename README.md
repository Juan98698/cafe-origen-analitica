# Café Origen - Analítica de Ventas

Proyecto de análisis y procesamiento de datos de ventas de café de especialidad utilizando JavaScript.

## Estructura del Proyecto

- `src/datos.js`: Conjunto de datos con los registros de ventas de la tienda.
- `src/explorar.js`: Script de prueba y exploración de los datos exportados.
- `src/analitica.js`: Módulo de funciones analíticas y procesamiento de métricas.
- `bitacora.md`: Registro de análisis exploratorio, diccionario de datos y decisiones de calidad.
